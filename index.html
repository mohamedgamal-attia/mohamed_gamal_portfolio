How I work

Five steps, no surprises

The same sequence on every engagement, whether it is one module or a whole ERP.

  1. 01

    Understand

    Sit with the people doing the work. Map the process as it is, not as the org chart says it is.

  2. 02

    Design

    Data model, approval routes and screens agreed in writing before any module is scaffolded.

  3. 03

    Build

    Custom modules on Odoo inheritance, in small reviewable increments on a shared branch.

  4. 04

    Validate

    Automated tests for the rules, browser tests for the journeys, UAT with the people who asked.

  5. 05

    Ship

    Deploy, train, then stay close for the issues that only appear once real users arrive.
